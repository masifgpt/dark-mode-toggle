# Dark Mode Toggle

A modern and responsive Dark Mode Toggle project built using HTML, CSS, and JavaScript with animated theme switching effects.

---

## Features

- Dark & Light Theme Toggle
- Smooth Theme Transition
- Local Storage Support
- Modern Glassmorphism UI
- Responsive Layout
- Animated Toggle Switch
- Mobile Friendly
- Interactive Hover Effects
- Clean Code Structure
- Fast Performance

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome
